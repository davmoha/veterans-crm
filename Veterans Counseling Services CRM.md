## ✨ Key Features

### Constituent Management
- Store unlimited volunteers, sponsors, and members
- Track contact information, roles, and preferences
- Organize by state, ZIP code, area code, contact type
- Add notes and custom fields

### Inline Editing
- Update records directly from the UI
- No forms or separate edit pages
- Changes saved instantly
- Full validation on all fields

### Advanced Search
- Filter by state (FL, Florida, etc.)
- Search by ZIP code
- Filter by area code (813, 305, etc.)
- Filter by contact type (Volunteer, Board, Member, Donor)
- Filter by email opt-in status

### Mass Email
- Select constituents using advanced filters
- Click "Send Email"
- Your email client opens with all selected addresses
- Compose and send directly from your device
- No email backend needed

### CSV Import
- Bulk upload constituents from conferences
- Download template to get started
- Automatic data validation
- Preview before importing
- Support for 10,000+ records

### User Management
- Add team members without SQL
- Promote/demote admins
- Delete inactive users
- Invite new members via email
- Role-based access control

### Field Reference
- Complete documentation of all 35 CRM fields
- Search by field name or data type
- View validation rules and automation triggers
- Understand dependencies and calculations

## 👥 User Roles

### Admin
- Full access to all features
- Can add/remove team members
- Can promote other admins
- Can manage all constituents
- Can import CSV files

### Regular User
- Can view and edit constituents
- Can search and filter
- Can send mass emails
- Can import CSV files
- Cannot manage team members

## 🔐 Security Features

- **HTTPS Encryption** — All data transmitted securely
- **Database Encryption** — Data encrypted at rest
- **OAuth Authentication** — Secure login
- **No Third-Party Sharing** — Your data stays with you
- **Automatic Backups** — Daily backups by Render
- **Role-Based Access** — Control who sees what
